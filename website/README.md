# YouTube Reimagined website

The extension landing page uses React and Vite. The popup previews and mascot come from the repository’s shared `assets` directory.

From `website/`, run `npm ci`, then `npm run dev` for local development. Run `npm run lint` and `npm run build` to check the site and generate the static files in `dist/`. Use `npm run preview` to serve the production build locally.

Both download buttons use the `Download` component in `src/App.jsx` and point to GitHub Releases.
